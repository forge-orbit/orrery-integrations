# Triage labels

| Role and GitHub label | Use |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the request. |
| `needs-info` | The reporter needs to provide more information. |
| `ready-for-agent` | An agent can implement the specified request. |
| `ready-for-human` | A human needs to implement the request. |
| `wontfix` | The maintainer declined the request. |

Use the label string as written when a skill gives a triage role.
